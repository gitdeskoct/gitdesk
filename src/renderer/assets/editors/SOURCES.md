# Editor logos

Each file is the vendor's own artwork, shown only beside that editor's name to say where Open in editor sends a file. None is redrawn or recolored. Downloaded 2026-10-26. XML prologs and doctypes were removed; every file was checked for scripts, event attributes and outside links.
